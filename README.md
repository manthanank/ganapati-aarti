# श्री गणपति आरती संग्रह | Shree Ganapati Aarti

> A peaceful, distraction-free devotional web application for chanting and reading sacred **Ganapati Aartis and Stotras** during **Ganesh Chaturthi (गणेशोत्सव)**, featuring pure lyrics, multi-script Indic transliteration, auto-scroll chant mode, interactive temple bell sound, and real-time live devotees presence.

---

## 🌟 Sacred Aartis & Stotras Collection

1. **सुखकर्ता दुःखहर्ता (Sukh Karta Dukh Harta)** — Samarth Ramdas Swami's quintessential Ganapati Aarti
2. **शेंदूर लाल चढायो (Shendur Lal Chadhayo)** — Traditional Aarti of Lord Ganesha
3. **जय गणेश जय गणेश देवा (Jai Ganesh Deva)** — Traditional Hindi Ganesh Aarti
4. **घालीन लोटांगण (Ghalin Lotangan)** — Traditional post-Aarti submission prayer
5. **मंत्रपुष्पांजली (Mantra Pushpanjali)** — ॐ यज्ञेन यज्ञमयजन्त देवाः (Universal Vedic prayer)
6. **संकटनाशन गणेश स्तोत्रम् (Sankat Nashan Ganesh Stotram)** — Narada Purana (प्रणम्य शिरसा देवं...)
7. **श्री गणपती अथर्वशीर्ष (Ganapati Atharvashirsha)** — Sacred Upanishadic hymn

---

## ✨ Features

- **Devoted to Pure Lyrics**: Clean, distraction-free typography for effortless chanting at home and in pandals.
- **5 Indic Script Formats**:
  - देवनागरी (मराठी / हिन्दी / संस्कृत)
  - English (Romanized Transliteration)
  - ગુજરાતી (Gujarati)
  - বাংলা (Bengali)
  - తెలుగు (Telugu)
- **Hands-Free Auto-Scroll (Chant Mode)**: Smooth auto-scrolling with speed options (`1x`, `1.5x`, `2x`) so you can chant along without touching your screen during puja.
- **Interactive Temple Bell (घंटी)**: Authentic brass temple bell resonance synthesized via Web Audio API with zero external audio dependencies.
- **Flower & Modak Shower (पुष्पवृष्टि)**: Interactive celebratory flower petal animation raining down sacred marigolds and hibiscuses.
- **Dynamic Font Zoom (`A-` / `A+`)**: Seamless scaling of lyrics text for easy viewing from any distance.
- **Instant Search**: Real-time filter across verses, transliterations, and meanings.
- **Live Devotees Presence**: Real-time counter showing devotees chanting worldwide.
- **100% Responsive Design**: Tailored for desktop, tablet, and mobile viewports.

## 🛠️ Technology Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: Vanilla CSS (modular design tokens, glassmorphism, responsive)
- **Audio Synthesis**: Web Audio API (zero external mp3 dependencies)
- **Icons & Favicon**: High-resolution sacred Lord Ganesha artwork

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm, yarn, or pnpm

### Installation

```bash
cd ganapati-aarti
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
