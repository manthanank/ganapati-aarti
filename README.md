# श्री गणपति आरती संग्रह | Shree Ganapati Aarti

## 🌟 Sacred Aartis & Stotras Collection

1. **सुखकर्ता दुःखहर्ता (Sukh Karta Dukh Harta)** — Samarth Ramdas Swami's quintessential Ganapati Aarti (Mayureshwar Morgaon)
2. **शेंदूर लाल चढायो (Shendur Lal Chadhayo)** — Traditional Aarti of Lord Ganesha
3. **जय गणेश जय गणेश जय गणेश देवा (Jai Ganesh Deva)** — Beloved Hindi Ganesh Aarti
4. **घालीन लोटांगण (Ghalin Lotangan)** — Traditional post-Aarti submission and prostration prayer
5. **मंत्रपुष्पांजली (Mantra Pushpanjali)** — ॐ यज्ञेन यज्ञमयजन्त देवाः (Universal Vedic prayer)
6. **संकटनाशन गणेश स्तोत्रम् (Sankat Nashan Ganesh Stotram)** — 12 sacred names from Narada Purana
7. **श्री गणपती अथर्वशीर्ष (Ganapati Atharvashirsha)** — Sacred Atharva Veda Upanishad

## ✨ Features & User Experience

- **Devoted to Pure Lyrics**: Clean, sacred, distraction-free typography for effortless reading and chanting at home and in public pandals during Ganeshotsav.
- **5 Indic Script Formats**:
  - **देवनागरी (मराठी / हिन्दी / संस्कृत)**
  - **English (Romanized Transliteration)**
  - **ગુજરાતી (Gujarati)**
  - **বাংলা (Bengali)**
  - **తెలుగు (Telugu)**
- **Hands-Free Auto-Scroll (Chant Mode)**: Smooth auto-scrolling with speed controls (`1x`, `1.5x`, `2x`) so you can sing along without touching your screen during puja.
- **Interactive Brass Temple Bell (घंटी)**: Authentic brass temple bell resonance synthesized via the **Web Audio API** with zero external audio dependencies, zero latency, and 100% offline support.
- **Flower & Modak Shower (🌸 पुष्पवृष्टि)**: Interactive celebration raining down sacred marigolds (झेंडू), red hibiscuses (जास्वंद), and modaks.
- **Dynamic Font Zoom (`A-` / `A+`)**: Step-by-step font scaling (85% to 145%) for comfortable chanting from any distance.
- **Instant Search**: Real-time filter across verses, transliterations, and Hindi/English meanings.
- **Verse Commentary**: Toggle between pure verse mode and detailed Hindi/English meanings.
- **Live Devotees Presence**: Real-time counter showing devotees chanting worldwide (`🟢 3,800+ devotees chanting`).
- **Sacred Particles Engine**: HTML5 canvas rendering floating golden embers and marigold sparkles.
- **100% Responsive Design**: Engineered and tested across all mobile, tablet, and desktop viewports.

## 🚀 Getting Started Locally

### Prerequisites

- Node.js (version 18+ recommended)
- npm, yarn, or pnpm

### Installation

1. Clone or navigate to the repository:
   ```bash
   cd ganapati-aarti
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
